# 🧠 Emotion Recognition from Social Media Text Using Large Language Models

An AI-based system that analyzes social media text and identifies the emotions expressed in the text using Transformer-based language models.

## 📌 Overview

Social media contains a large amount of text where people express their thoughts, opinions, and emotions. Traditional sentiment analysis usually classifies text as positive, negative, or neutral, but it cannot identify specific emotions such as joy, sadness, anger, fear, surprise, or love.

This project uses Transformer-based language models for fine-grained emotion recognition from social media text.

The system performs text preprocessing, tokenization, text normalization, feature extraction, and emotion prediction. :chatgpt-content-reference{index="1"}

---

## 🎯 Objectives

- Detect emotions from social media text.
- Perform fine-grained emotion classification.
- Preprocess and normalize text before prediction.
- Generate confidence scores for predicted emotions.
- Visualize emotion prediction results.
- Evaluate the model using standard classification metrics.

---

## 🧠 Emotion Detection

The system can identify emotions such as:

- Joy
- Sadness
- Anger
- Fear
- Surprise
- Love
- Neutral

The project uses a Transformer-based approach for emotion classification. :chatgpt-content-reference{index="2"}
